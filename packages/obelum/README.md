# obelum

The unscoped name for [`@obelum/core`](https://github.com/maxmart/obelum/tree/main/packages/core).
`import { … } from 'obelum'` and `import { … } from '@obelum/core'` are the
same thing; this package re-exports it and pins the same version.

See the repository for what Obelum is and for the other packages
(`@obelum/translator-claude`, and the store and CLI that are planned).
